# chambrehomme.github.io

A personal blog exploring technology, artificial intelligence, software engineering, and ideas I personally find
worth thinking about.

**Live site:** [chambrehomme.github.io](https://chambrehomme.github.io/)

## About this project

This repository contains the source code and written articles for my personal blog. It is a space to document what I
learn, explore emerging technologies, and share perspectives on the tools and ideas shaping software development.

## What you'll find here

- **Artificial intelligence:** perspectives on AI, its evolution, and its impact.
- **Software and engineering:** technical concepts, tools, and development practices.
- **Ideas and learning:**  notes and reflections on topics I find interesting.

*Topics reflect the current direction of the blog and will evolve.*

## Built with

- [Jekyll](https://jekyllrb.com/): static site generation.
- [GitHub Pages](https://pages.github.com/): hosting and publishing.
- Markdown and YAML: writing and site configuration.

## Project structure

- `_posts/`: published articles.
- `_config.yml`: site metadata and Jekyll configuration.
- `index.md` or `index.html`: homepage content, depending on the current setup.
- `assets/`: stylesheets, fonts, and images, if present.

## Local development

If Ruby and the project's Jekyll dependencies are installed:

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000` in your browser.

## Philosophy

This blog is a work in progress: a place to learn in public, develop my thinking, and make useful ideas accessible to
others.
